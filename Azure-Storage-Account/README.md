## 📖 نبذة عن التقرير
يقدم هذا التقرير دليلاً أكاديمياً وتطبيقياً شاملاً حول خدمة **Azure Storage Account** في منصة Microsoft Azure. يستعرض التقرير البنية التحتية لحساب التخزين السحابي، آليات الأمان والحماية، خيارات التكرار والتوافر العالي، مع توثيق كامل لخطوات التنفيذ العملي خطوة بخطوة داخل بوابة أزور (Azure Portal) مدعمة بلقطات الشاشة الواقعية.

---

## 🗂️ المحاور الرئيسية للتقرير

### 1. الجانب النظري والمعماري
* **مفهوم حساب التخزين (Storage Account):** الحاوية الإدارية ونقطة الدخول الموحدة (Namespace) لجميع خدمات التخزين السحابي.
* **خدمات التخزين الأساسية الأربع:**
  * **Blob Storage:** تخزين الكائنات الثنائية الكبيرة غير المنظمة (Block Blobs, Append Blobs, Page Blobs).
  * **Azure Files:** مشاركات الملفات عبر بروتوكولات الشبكة التقليدية (SMB / NFS).
  * **Queue Storage:** معالجة الرسائل غير المتزامنة وفصل مكونات النظام (Decoupling).
  * **Table Storage:** قاعدة بيانات NoSQL سريعة لتخزين الأزواج المفتاحية (Key-Value).
* **التسلسل الهرمي:** توضيح الفرق الجوهري بين `Storage Account` و `Blob Container` و `Blob`.

### 2. الأمان، التكرار، والتكلفة
* **إدارة التكرار والتوافر (Redundancy):** مقارنة تفصيلية بين أنواع التكرار (LRS, ZRS, GRS, GZRS) وأثرها على التكلفة والتعافي من الكوارث.
* **الوصول العام مقابل الخاص (Public vs. Private Access):** المخاطر الأمنية لكشف البيانات والبدائل الآمنة.
* **ضوابط الأمان:** التشفير أثناء التخزين (Encryption at Rest بمستوى AES-256)، فرض اتصال HTTPS، وتوليد تواقيع الوصول المشترك المحدودة زمنياً (Shared Access Signature - SAS)، وإدارة الهويات عبر Microsoft Entra ID.

### 3. التطبيق العملي (Hands-on Lab)
* إنشاء مجموعة الموارد (`Resource Group`).
* تكوين ونشر حساب التخزين مع مراعاة خيارات الأداء والتكرار.
* إنشاء حاوية بيانات (`Blob Container`) وضبط الوصول على Private.
* رفع الملفات، استعراض الروابط المباشرة، وتوليد روابط SAS مؤمنة للمشاركة.
* إنشاء ومشاركة ملفات عبر `File Share`.
* مراجعة وتحليل أفضل الممارسات وحل المشاكل الشائعة (Troubleshooting & Best Practices).
