# وثيقة مواصفات متطلبات البرمجيات الآمنة (SSRS / SRS)
**Building Materials Sales Management System (BMS-Sales)**

---

## 📖 نظرة عامة
وثيقة متكاملة لتوصيف متطلبات نظام إدارة مبيعات مواد البناء، تم بناؤها وفق معايير **IEEE 830** مع دمج معايير الأمان المباشر بالتصميم (**Security-by-Design**). تغطي الوثيقة كافة المتطلبات الوظيفية وغير الوظيفية ومخططات النمذجة والتحليل الهندسي للنظام.

---

## 🗂️ محتويات الوثيقة ومخططات النظام
1. **المتطلبات الوظيفية والأمنية:**
   * إدارة المستخدمين والصلاحيات وفق نموذج التحكم بالوصول المستند إلى الأدوار (RBAC).
   * إدارة نقاط البيع (POS) والفواتير وطرق الدفع وتكامل سقف الائتمان للعملاء.
   * إدارة المشتريات والموردين وحساب المخزون الآلي.
   * إدارة الأمان، تشفير كلمات المرور، تسجيل التدقيق الأمني (Audit Log)، ومنع حقن الاستعلامات (SQL Injection).
2. **المخططات الهندسية ونمذجة النظام:**
   * **مخطط الكيانات والعلاقات (ERD):** الهيكل الكامل لقاعدة البيانات العلائقية ومستودعات التخزين.
   * **مخططات تدفق البيانات (DFD):** تشمل المخطط البيئي (Context Diagram)، المخطط الصفري (Level 0)، ومخططات المستوى الأول التفصيلية لعمليات البيع والجرد.
   * **مخططات الـ UML:** تشمل مخطط حالات الاستخدام (Use Case)، مخطط الفئات (Class Diagram)، المخطط التسلسلي (Sequence Diagram)، ومخطط النشاط (Activity Diagram) لمسار الفواتير والاعتماد المالي.
